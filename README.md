# SNS — Minecraft Launcher

**SNS** is a Minecraft: Java Edition launcher for Windows. It has a dark "instrument panel" look, your own modpacks, and mods from Modrinth and CurseForge in one place.

### ⬇ [Download the latest version](https://github.com/SNOYP/Minecraft_SNS/releases/latest)

Open the link and download **`SNS-setup-<version>.exe`** under **Assets**.

---

## Installation

1. Download `SNS-setup-<version>.exe` from [Releases](https://github.com/SNOYP/Minecraft_SNS/releases/latest).
2. Run it. SNS installs itself and creates shortcuts on the desktop and in the Start menu.
3. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. The installer is not code-signed, which is normal for small independent projects.

**Updates are automatic.** When a new version is released, SNS offers to update on start. One click and it restarts updated. Your packs, worlds and login are kept.

**Requirements:** Windows 10 / 11 (64-bit), an internet connection for the first launch. Java is downloaded by SNS automatically.

## Features

- **Sign-in:** Microsoft account with Minecraft: Java Edition. There is also an offline mode with just a nickname, for servers that allow it.
- **Modpacks:** Vanilla, Fabric, Forge, NeoForge and Quilt, any Minecraft version. Each pack has its own folder, mods, RAM and Java.
- **Catalog:** search and install mods and ready-made modpacks from Modrinth, with dependencies.
- **Pack codes:** press *Share* and send a short code like `SNS-2K9-QX7M` — your friend pastes it and the pack downloads by itself. Only mods, configs, resource packs and shaders are shared; worlds, screenshots and your settings stay yours. CurseForge profile codes and Modrinth share links work too.
- **Import / export:** packs from CurseForge, Modrinth App, Prism and FTB App in one click, CurseForge `.zip`, Modrinth `.mrpack`; share your pack as `.mrpack`.
- **Mod updates** with one button.
- **Worlds and screenshots:** backups and restore, screenshot gallery.
- **Skins and capes:** 3D preview with poses, skin library, cape switching (licensed accounts).
- **Look:** themes and any accent color, live background, launch animation with progress.
- **12 languages:** English, Русский, Українська, Deutsch, Polski, Español, Français, Português, Italiano, Türkçe, 简体中文, 日本語.
- **Playtime statistics** for every pack.

## FAQ

**Where are my files?** Settings and accounts are in `%APPDATA%\SNS`. Games, packs and Java go to `%APPDATA%\SNS\data` by default; you can change the folder in **Settings**.

**Something doesn't work.** Open **Settings → open log** and send the `sns.log` file to the author.

**How do I uninstall?** Windows **Settings → Apps → SNS → Uninstall**.

# 🇷🇺 SNS — лаунчер Minecraft

**SNS** — лаунчер Minecraft: Java Edition для Windows. Тёмное оформление в стиле приборной панели, свои сборки, моды с Modrinth и CurseForge в одном месте.

### ⬇ [Скачать последнюю версию](https://github.com/SNOYP/Minecraft_SNS/releases/latest)

Открой ссылку и скачай **`SNS-setup-<версия>.exe`** в разделе **Assets**.

## Установка

1. Скачай `SNS-setup-<версия>.exe` из [Releases](https://github.com/SNOYP/Minecraft_SNS/releases/latest).
2. Запусти его. SNS установится сам и создаст ярлыки на рабочем столе и в меню «Пуск».
3. Если Windows пишет **«Система Windows защитила ваш компьютер»**, нажми **Подробнее → Выполнить в любом случае**. У установщика нет цифровой подписи, для небольших проектов это нормально.

**Обновления приходят сами.** Когда выходит новая версия, SNS при запуске предложит обновиться. Одна кнопка, и он перезапустится уже новым. Сборки, миры и вход сохраняются.

**Нужно:** Windows 10 / 11 (64 бита), интернет при первом запуске. Java SNS скачивает сам.

## Возможности

- **Вход:** аккаунт Microsoft с Minecraft: Java Edition. Есть и вход без лицензии, просто по нику, для серверов, где это разрешено.
- **Сборки:** Vanilla, Fabric, Forge, NeoForge и Quilt, любая версия Minecraft. У каждой своя папка, моды, ОЗУ и Java.
- **Каталог:** поиск и установка модов и готовых сборок с Modrinth вместе с зависимостями.
- **Коды сборок:** нажми *Поделиться* и отправь короткий код вроде `SNS-2K9-QX7M` — друг вставит его, и сборка скачается сама. Передаются только моды, конфиги, ресурспаки и шейдеры; миры, скриншоты и твои настройки остаются у тебя. Работают и коды профилей CurseForge, и ссылки Modrinth.
- **Импорт и экспорт:** сборки из CurseForge, Modrinth App, Prism и FTB App в один клик, `.zip` с CurseForge, `.mrpack` с Modrinth; свою сборку можно отдать как `.mrpack`.
- **Обновление модов** одной кнопкой.
- **Миры и скриншоты:** бэкапы и восстановление, галерея скриншотов.
- **Скины и плащи:** 3D-превью с позами, библиотека скинов, смена плаща (для лицензии).
- **Оформление:** темы и любой цвет, живой фон, анимация запуска с прогрессом.
- **12 языков** интерфейса.
- **Статистика** времени в игре по каждой сборке.

## Вопросы

**Где мои файлы?** Настройки и аккаунты лежат в `%APPDATA%\SNS`. Игра, сборки и Java по умолчанию в `%APPDATA%\SNS\data`, папку можно сменить в **Настройках**.

**Что-то не работает.** **Настройки → открыть журнал**, отправь файл `sns.log` автору.

**Как удалить?** **Параметры Windows → Приложения → SNS → Удалить**.
